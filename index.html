Projects

Nigeria Job Market Tracker

A daily pipeline that pulls Nigerian job listings from the Jooble API, cleans and deduplicates them, and shows hiring trends on a public dashboard.

Raw JSON loads into Postgres, dbt models build the cleaned jobs table and analytics tables (top companies, work mode, job type, jobs per week, top skills), and dbt tests run on every refresh. GitHub Actions runs it daily against a hosted Neon Postgres database.

Fantasy Premier League Data Pipeline

An automated pipeline that collects Fantasy Premier League data and keeps it queryable in Postgres, built for a group of FPL managers who wanted access to their data in the off-season.

Orchestrated with Apache Airflow 3.0 in Docker, with separate databases for Airflow metadata and pipeline data. It handles the FPL API’s bot protection and is deployed on an AWS EC2 instance.

AirflowDockerPostgreSQLPythonAWS EC2

Premier League Analysis & Power BI Dashboard (2021–2023)

Cleaned and analysed three seasons of English Premier League match data with Pandas, ran deeper queries in Postgres, and built an interactive Power BI dashboard.

Cleaning covered missing values, duplicates and data types, saved as Parquet and CSV. Exploratory analysis in Matplotlib looked at goals, results, fouls, cards and attendance. SQL queries found top scoring stadiums and the teams with the most wins and draws. The dashboard pulls it together.

Online Retail Store Analysis & Power BI Dashboard

Analysis and an interactive dashboard of a year of sales for an online retail store whose customers are mainly in European countries.

Cleaned and structured the data with Pandas, then explored total revenue, top-selling products, the sales trend over the year, the link between quantity and unit price, and which countries had the most customers. The dashboard highlights customer and product KPIs, and the cleaned data is exported as CSV and Parquet.
